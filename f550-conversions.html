Cab chassis

Ford F-550 conversions

An F-550 is not a bigger F-450. It arrives as a cab chassis — cab, frame rails, and nothing behind them — because what goes on the back is yours to decide: a flatbed, a service body, a hauler bed, a camper. That one difference changes how the truck has to be built, and it is why we quote an F-550 per build rather than from a package price.

What does not change is the work. Same LiquidSpring suspension, same Goodyear G275s on two-piece wheels, same SSBC Beast brakes front and rear, same bodywork cut and fitted on our own floor in Escondido, California.

Why it is quoted per build

No two are the same truck

On an F-450 pickup the back of the truck is a known quantity, which is what makes a package price possible. On a cab chassis it is not. Wheelbase, cab configuration and whatever body is going on determine the flare work, the bumper, the lighting and how the suspension is specified — the build above runs 2" of lift at the front and 4" at the rear, which is a decision about that truck.

So we price it from the parts list, the same catalog every MAV build is quoted from, and you see the line items. We source the chassis through our Ford dealer network and build the truck start to finish — tell us the configuration you want and what is going on the back, and we will put a number against it.

  • F-350, F-450, F-550 and F-600 cab chassis
  • 2" or 4" of lift, front and rear specified separately
  • 41" or 44" Goodyear G275 on two-piece wheels
  • RAM 4500 and 5500 cab chassis built to the same standard

Questions we get

F-550 conversions, answered

What is the difference between an F-450 and an F-550 conversion?

The F-450 we build is a pickup, so the bed is already on it and the conversion is a known package — that is the Summit and the Apex. An F-550 is a cab chassis with nothing behind the cab, so the build has to account for whatever body is going on the back. Same suspension, wheels, brakes and bodywork; a different quote every time.

Will it still take a flatbed or service body?

Yes — that is the point of a cab chassis, and we build around it. Tell us what body is going on and at what stage, because it changes the flare work and how the rear suspension is specified.

What does an F-550 conversion cost?

It is quoted per build rather than from a package price, because no two cab chassis trucks are specified the same way. The quote covers the chassis and the conversion together — we source the truck through our Ford dealer network and build it from there — and it is priced off the same parts catalog every MAV build is quoted from, so you see the line items. Do you build on RAM cab chassis too?

Yes. We fit the same LiquidSpring suspension to RAM 4500 and 5500 cab chassis, in 2" front and 2" or 4" rear, with the matching heavy-duty rear sway bar.

How long does an F-550 build take?

Six to eight weeks once the truck is at our facility, the same as a pickup build. Total time from order also depends on availability of the chassis you want.
